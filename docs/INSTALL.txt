Speak2Mic (x64) — виртуальный кабель: "Speak2Mic Speaker" (воспроизведение) -> "Speak2Mic Microphone" (микрофон)
=========================================================================================================
(English: INSTALL.txt)

ВАЖНО: драйвер подписан тестовым сертификатом, поэтому нужен тестовый режим подписи Windows.
Устанавливайте в виртуальной машине и сначала сделайте снапшот.

1. Подготовка (один раз)
   - VMware: выключите ВМ, VM > Settings > Options > Advanced > снимите "Enable UEFI Secure Boot".

2. Установка
   - Запустите Speak2Mic-Setup.exe (попросит права администратора). Окно покажет состояние системы.
   - Если тестовый режим подписи выключен: "Включить тестовый режим" -> перезагрузка ->
     снова Speak2Mic-Setup.exe.
     Та же кнопка потом выключает режим ("Выключить тестовый режим" -> перезагрузка). Без тестового
     режима драйвер не загружается: устройства Speak2Mic пропадут, пока режим не включат снова.
   - "Установить". Если Windows предупредит, что не может проверить издателя, выберите
     "Все равно установить этот драйвер".
   - Галочки "Ярлык на рабочем столе" и "Ярлыки в меню «Пуск»" — по желанию.
   - Программы копируются в C:\Program Files\Speak2Mic\ (оттуда же потом можно запустить
     Speak2Mic-Setup.exe для переустановки, диагностики и удаления — ярлык в меню «Пуск»).
   - В Параметрах звука появятся "Speak2Mic Speaker" и "Speak2Mic Microphone", затем откроется Speak2Mic.exe.
   - Запасной вариант без окна: install.cmd от имени администратора
     (тестовый режим тогда включите сами:  bcdedit /set testsigning on  и перезагрузка).

3. Звук ВМ -> виртуальный микрофон
   - Параметры -> Система -> Звук: устройство вывода "Speak2Mic Speaker".
   - В программах записи выберите микрофон "Speak2Mic Microphone". Индикаторы в Speak2Mic.exe показывают сигнал.
   - Чтобы звук было слышно: Панель управления -> Звук -> Запись -> "Speak2Mic Microphone" -> Свойства ->
     "Прослушать" -> "Прослушивать с данного устройства" -> динамики VMware.

4. Качество сигнала
   - Speak2Mic.exe, блок "Качество сигнала кабеля": пресет или частота/разрядность/каналы -> "Применить".
     Панель перезапустит драйвер и сама выставит устройствам Speak2Mic этот формат по умолчанию
     (то, что видно в "Звук" -> Свойства -> Дополнительно -> "Формат по умолчанию").

5. Имена устройств и сброс
   - Speak2Mic.exe, блок "Имена устройств": впишите свои имена -> "Переименовать" (пустое поле —
     имя по умолчанию). Кнопка "Сбросить все настройки" вверху слева возвращает пресет "Стандарт"
     и стандартные имена (язык не меняется).
   - "Экспорт настроек…" / "Импорт настроек…" внизу окна: файл .ini с качеством сигнала, именами,
     громкостью микрофона и "Без звука" (язык не сохраняется).

6. Язык интерфейса
   - По умолчанию — язык системы (Windows или региональные настройки), если он среди 17 языков,
     иначе английский. Выбранный вручную язык запоминается. Сменить: список "Язык" в
     правом верхнем углу Speak2Mic.exe или Speak2Mic-Setup.exe; программа перезапустится.
     Консольный s2minstall.exe: ключ --lang ru|en|uk|be|de|...

7. Удаление
   - Speak2Mic-Setup.exe -> "Удалить" (или uninstall.cmd от имени администратора). Удаляются драйвер,
     программы из C:\Program Files\Speak2Mic и ярлыки.

Журналы
   - Все программы пишут журнал в C:\ProgramData\Speak2Mic\logs\ (setup.log, panel.log,
     install.log, ctl.log, autotest.log). Драйвер ведёт свой журнал в реестре; Speak2Mic-Setup.exe -> "Диагностика" добавляет его
     в setup.log вместе с состоянием устройства и фрагментом C:\Windows\INF\setupapi.dev.log.
   - Если что-то не работает: Speak2Mic-Setup.exe -> "Диагностика" -> "Открыть журнал" и пришлите setup.log.

Если что-то пошло не так
   - Код 52 в диспетчере устройств: не включён тестовый режим или включён Secure Boot.
   - Синий экран: откатите снапшот и пришлите файл C:\Windows\Minidump\*.dmp — по нему видно ошибку.
   - Щелчки: увеличьте задержку в Speak2Mic.exe (50–100 мс).
